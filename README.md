# Soil-MFC

This project explores low-energy, waste-derived materials for microbial fuel cells (MFCs), aiming to develop bioelectrochemical systems for environmental sensing and soil regeneration. It investigates chitosan and oyster shell as alternative bio-based materials for MFC membranes, and chitosan cross-linked with citric acid as an alternative binder to PTFE for activated-carbon cathodes. The unfired biocomposite membrane can be fabricated from food-waste materials with minimal energy input and offers flexible forming possibilities, including moulding, 3D printing and hand forming.

In this repository, you can find:
* CAD files of the 3D print mould for casting the chassis/membrane
* Code for muti-channel voltage datalogger
* And more is coming :)
